# Generic linker-path binding development gate

Status: bounded, zero-oracle development experiment, not an official fragment
benchmark row. The prior matched-arm diagnostic at
`diagnostics/fragment_linker_matched_v1/matched_analysis_with_provenance.json`
showed a genuine-linker/commit-rate tradeoff: 421/422 path-program commits
lengthened the one-atom seed, but only 422/3,000 attempts committed. A new
refusal census on three selected seed-0 prompts, ten attempts each, is
development evidence only. It reproduces the original first ten emitted
samples exactly and shows 20/21 offered transactions with no prior-sampled
site-matching insertion on FUTIBATINIB and LOVASTATIN (21/34 across all
three), plus 6/12 found
insertions refused at the insert step on ELIGLUSTAT. These prompts were chosen
after observing the failure; they are not held-out evidence.

One generic candidate is permitted. For a two-core path transaction, sample
an `atom_insert` payload from the unchanged learned prior and retain its atom
identity, formal charge and valence class. Bind its new atom to the path site
specified by the supplied fragment interfaces, irrespective of the site at
which the prior originally drew it. If its original one-neighbor bond order
was greater than one, recompute implicit hydrogens for a single bond while
preserving the prior's valence class. The executor must still accept both the
insert and the atomic bridge reroute, and the exact region lock must still
hold. Do not invent an atom, choose an element by task, alter a prompt, relax
chemical validity, or change one-core sampling.

Compare this candidate with the immutable old first-ten attempts on the same
three prompts and seed, using an implementation/version/asset-hashed artifact.
The intervention is a *signal* only if `path_payload_absent` falls, the
accepted path transactions and genuine >seed endpoints rise, all committed
endpoints remain exact-valid and connected, and no prompt's attempt-level
quality falls by more than one molecule. If it fails, keep the negative
result and reject it. If it passes, this is still development evidence; freeze
the policy and test on unused seeds before considering a full official row.
The one-atom seeded bridge remains a disclosed constructed start condition.
