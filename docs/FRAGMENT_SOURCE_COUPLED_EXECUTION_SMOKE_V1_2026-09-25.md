# Source-coupled decoration execution smoke

The current scaffold-decoration joint-mass sampler reached 37.0% quality,
97.0% uniqueness, 0.55655 diversity, and 100% validity in its completed
200-attempt development panel. Uniform sampling within its training-content
cells raised diversity in a later matched pilot but failed its frozen quality
gate. A separate training-source-coupled law preserves the independent proposal
lane and samples compatible pendants from one training source row in half of
supported draws. Its zero-quality support census found compatible rows for
1,409/1,478 model-supported offers, but measured fewer distinct content plans
than the original independent law. It has not been tested under exact
model-scored execution.

This smoke compares the unchanged joint-mass sampler with the existing
half-coupled law on all ten pinned scaffold-decoration prompts. Each arm makes
three complete eight-offer attempts per prompt, for 60 attempts and 480 offers
in total. The runner records every offer, exact compiled and model-supported
counts, selected endpoint, executor validity, pathwise graph protection, exact
prompt fidelity, and use of a shared training source. It uses the same
split-first pendant catalog, train-only mass prior, RingCore checkpoint,
executor and learned panel selector in both arms. The proposal contains no
benchmark-quality labels, QED/SA calls, target identity heuristic, or drug-
specific policy.

The result will determine only whether the source-coupled law maintains
execution, model support, and structural fidelity on this small panel.
Neither quality nor diversity is evaluated. A scored development comparison
would require a separate frozen contract and authorization. No prior pilot or
running linker campaign is modified.

Runner: `tools/run_fragment_source_coupled_execution_smoke_v1.py`.
Output: `diagnostics/fragment_source_coupled_execution_smoke_v1/result.json`
with per-attempt receipts in the same directory. The code pins the exact input
hashes, prompts, arms, seed derivation, offer count, and output directory, and
publishes the complete result directory atomically.
