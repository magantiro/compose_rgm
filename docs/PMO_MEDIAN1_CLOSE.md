# PMO Median1 one-query closeout

## Scientific question

The exact IVG-core oracle audit leaves one completed-task miss: Median1 trails
IVG's prescreen AUC by 0.001550419204571274. The public IVG panel contains a
shared molecular construction whose O, S, N, F, Cl and Br substituent analogues
all score near 0.395. This experiment tests one pre-score extrapolation: replace
the variable substituent with iodine.

The candidate remains a complete molecule within COMPOSE's declared neutral,
40-active-atom, 48-slot support. It is compiled from the same generic Median1
root as one 14-primitive complete edit program and exact-replayed before the
task oracle is called.

## Evidence class and claim boundary

The public panel and prior eleven scores are reported or measured development
evidence. The iodine candidate is generated by a declared structural analogy.
Its reward is unknown at lock time. A positive result is therefore a
prospective one-candidate panel-series extrapolation, but it remains inside an
answer-known, winner-informed task curriculum. It is not held-out evaluation,
autonomous 10,000-query search, or general PMO superiority.

The public source is the official `InVirtuoGen_results` repository at revision
`b50bb3ae2bdcb9df581f0b219d79cf14b05d0fbb`, licensed CC BY-NC-SA 4.0. The
contract records the path and SHA-256 of the source panel.

## Frozen workflow

1. Verify the parity contract and prior result by SHA-256.
2. Convert `CC1CCCCC1O` to an exact 48-slot source state.
3. Compile the predeclared iodine endpoint into one complete program.
4. Exact-replay it and require the declared canonical endpoint, no formal
   charges, no more than 40 active atoms, at most 96 primitives and at most two
   blocks.
5. Seal the one-query lock from clean committed code.
6. Under the exact IVG-core environment, verify the PyTDC source identities,
   write a started receipt, evaluate Median1 exactly once, and write a completed
   receipt. Automatic retry and replacement are forbidden.
7. Append the single score to the immutable eleven-query chronology and compute
   the official top-ten AUC at budget 10,000, frequency 100 and `finish=True`.

## Acceptance and stopping rule

- Exactly one candidate is locked and exact-replayed before scoring.
- Exactly one started and one completed receipt exist, with no failure or retry.
- The cumulative result includes all eleven prior observations in their original
  order followed by the new observation.
- The negative outcome is retained if the candidate does not improve AUC.
- The task closes only if cumulative AUC is strictly greater than
  0.3861480499242786.
- No additional candidate is substituted after observing the result.
