# Linker panel selection with bounded novelty weighting

## Scientific identity and scope

The problem is repeated linker endpoints at the 100-attempt benchmark scale. A
generated object remains one complete executable COMPOSE program joining the
two supplied fragments. The hypothesis is that a modest, stochastic preference
for as-yet-unreturned canonical endpoints within each eight-offer panel can
increase distinct valid yield without changing the frozen proposal process or
the chemical and structural constraints.

This revision prepares an optional selector only. It does not alter the running
official linker or motif evaluations, the running cell-allocation pilot, the
frozen reference checkpoint, the executor, the connector catalog, the joint
structural prior, or the official evaluator. It makes no oracle or docking call
and does not launch a scored pilot. The default selector must remain byte- and
RNG-equivalent to the existing learned-score softmax.

The proposed development comparison has two arms. `frozen` uses the current
unit-temperature learned-score softmax. `novelty4` multiplies the softmax weight
of each model-supported endpoint not previously returned for that prompt by
four. Every supported endpoint retains positive probability, including a
previously returned endpoint. The archive contains only endpoints emitted in
earlier attempts of the same prompt and arm. It contains no quality label,
target identity, benchmark comparator, or rejected offer. The eight offers,
within-panel canonical deduplication, exact execution and scoring remain
unchanged. A duplicate selection is recorded and counted, never replaced.

The declared support is the existing 40-active-atom, 48-slot,
32-primitive, eight-block non-stereochemical molecular graph process. The
split-first training connector catalog supplies proposal content. The supplied
fragments determine structural interfaces but do not supply fitted content.

## Proposed prospective gate

Before any scored launch, freeze a self-hashed contract and a clean committed
source revision. The matched development panel would use all ten pinned linker
prompts, a fresh seed excluded from official seeds 1-3 and the running
cell-allocation seed 4, 100 attempts per prompt and arm, eight offers per
attempt, one CPU worker and the same frozen checkpoint. Lock all selected
outputs before running the pinned official fragment evaluator. Record every
offer, score, selection probability, archive size, RNG state, refusal, output,
duration, validity and exact core/path fidelity. Missing outputs remain in the
denominator. Scaffold morphing is the same prompt/output set, not an independent
replicate.

The predeclared promotion gate requires at least 1,000 outputs, 100% chemical
validity and exact core/path fidelity in each arm. Relative to the matched
`frozen` arm, `novelty4` must gain at least three quality points and eight
uniqueness points, with diversity falling by no more than 0.02. A failed gate
is retained as a negative result. Passing this development gate only qualifies
the selector for a subsequent fresh-seed evaluation; it does not replace the
ongoing official result or authorize combining this intervention with the
cell-allocation intervention.

The published GenMol and InVirtuoGen values are offline comparators. QED, SA,
benchmark quality and diversity labels may be computed only after output lock
and cannot influence the selector. A scored pilot requires separate launch
authorization bound to its exact contract payload hash.
