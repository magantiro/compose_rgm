# PMO route-proposer production support audit

## Outcome

The sealed PMO route-distillation export is useful training supervision, but it
cannot be used directly as a production proposal policy. The zero-oracle gate
therefore stops before candidate sampling instead of comparing the real Dynamic-v0
sampler against an invented or teacher-reconstructed route arm.

The export contains 6,143 task-free primitive decisions. Every row contains a
517-dimensional state descriptor, an 18-field stage descriptor and structural
operand roles. The 4,557 rules that require typed parameters contain their expected
non-address parameters; the remaining 1,586 rows are deletion or cycle-open rules
whose empty parameter mappings are expected. The export also records 1,231 rows
with created-handle dependencies and 1,531 created outputs.

What it intentionally does not contain is decisive: zero rows contain an exact
current graph, runtime atom binding, executable teacher action or complete
dependency-region target. The sealed metadata also states that no actor or binding
prototype target was emitted and that all decisions are primitive fallbacks. A
structural operand descriptor such as degree, element and neighborhood histogram is
not a unique legal atom assignment. Treating it as one would fabricate training
information and could silently select a different action.

## Frozen pilot scope

The intended later pilot remains Celecoxib rediscovery, GSK3B and Perindopril MPO,
using the immutable 16-source PMO initialization. Every route checkpoint must hold
out the exact task and every shared lineage before fitting. The later zero-oracle
comparison must give the unchanged Dynamic-v0 sampler and additive route sampler
the same number of actual production attempts and report validity, uniqueness,
exact execution, work and wall time.

No asymmetric baseline was run here. Running Dynamic-v0 alone would produce a
number, but it would not answer whether the route proposer improves production
yield under matched attempts.

## Smallest missing asset

The next revision needs a split-first exact region/binding corpus aligned to the
already locked 184 route traces. For each training decision it must contain:

1. the exact current molecular graph;
2. the complete dependency-region target or canonical teacher successor;
3. the legal bound action and typed-parameter realization receipt;
4. route order, STOP and relative created-handle dependencies; and
5. the frozen whole-task-family and shared-lineage split identity.

This is not a request for another compiler or a scored experiment. It is the
minimal graph-to-legal-binding bridge needed to fit and independently verify one
leave-one-task-out runtime proposer per pilot task. After those checkpoints exist,
run the equal-attempt 16-source sampler comparison. Only a passing result should
advance to the blind versus FiberControl factorial.
