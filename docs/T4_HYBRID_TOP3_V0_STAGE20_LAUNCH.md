# T4 hybrid top-three plus Dynamic-v0 Stage-20 launch

This launch measures one frozen five-cell development controller through charged
call 20. JAK2 seed 1 and PARP1 seed 0 spend calls 1 through 3 on the three
prelocked score-blind macro candidates, then hand every finite observation to
one run-local archive before unchanged Dynamic-v0 begins at call 4. The other
three cells preserve the recorded macro-support abstention and start unchanged
Dynamic-v0 at call 1.

The stage uses five independent one-CPU workers and permits at most 20 charged
calls per cell, 100 total. It has no automatic retry, replacement, backfill,
confirmation or plateau stopping. Best-so-far values are reported at exactly
calls 1, 5, 10 and 20. A missing call remains missing.

Every query is reserved and committed before docking and committed again after
the result. Round candidate locks, the complete measured-program archive,
program ancestry, query receipts, best-so-far curve and exact random-number
generator state are persisted. Call 20 creates a stage result rather than a
terminal full-run result, permitting a separately authorized extension to calls
50 and 100 from the same checkpoint and run namespace.

This is an answer-known five-cell development diagnostic. It is not a full T4
benchmark, held-out evidence or IVG superiority evidence. The machine-readable
authority is `configs/t4_hybrid_top3_v0_stage20_launch_v1.json`.
