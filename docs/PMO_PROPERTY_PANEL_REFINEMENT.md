# PMO property-panel refinement

## Problem and narrow claim

The completed single-anchor property wave reproduced one excellent public
structure per task, but generic one-edit variants diluted the top-ten archive.
This bounded follow-on tests whether broader, task-appropriate structural
support from a public top-molecule panel produces a stronger executable COMPOSE
curriculum.

The output is ten complete, exact-replayed COMPOSE programs per task and one
counted oracle result for each program endpoint plus the same unrelated root.
This is answer-known development. It is not held-out discovery, an autonomous
search result or evidence of general PMO superiority.

## Frozen inputs and evidence roles

The tasks are QED, GSK3B and JNK3. The contract pins the official IVG source
revision, top-molecule panel hashes, and both comparator CSV hashes. Candidate
records distinguish exact panel transcriptions, other panel transcriptions,
and explicitly panel-derived structural variants. No derived variant is
reported as an independently published IVG molecule.

QED uses the pinned PyTDC 0.3.6 oracle. GSK3B and JNK3 use the frozen flat-tree
evaluators whose parameter and official source-pickle identities already passed
the preceding wave. DRD2 remains excluded because its current official pickle
does not byte-match the local frozen model and no decision-parity artifact is
available.

## Frozen procedure

1. Load and hash-verify the same unrelated neutral exact COMPOSE root.
2. Canonicalize every predeclared structure and enforce neutral, at-most-40-atom
   support and uniqueness within each task before route construction.
3. Compile the first task structure from the root. For each remaining structure,
   first attempt a two-block base-plus-suffix program. If that route is not
   available under the frozen compiler budget, attempt one direct root program
   and record the compilation mode.
4. Execute every complete program through the exact executor. Abort before
   scoring unless all 30 endpoints exactly match their locked targets.
5. Score the root and ten endpoints once per task. A started query is never
   automatically retried, and failed endpoints are never replaced.
6. Compute the official PMO top-ten AUC at a 10,000-query denominator,
   frequency 100, and `finish=True`. Compare exact margins with both IVG modes.

The total ceiling is 33 new local CPU oracle calls. Support remains neutral
charge-preserving graphs with at most 40 active atoms in 48 persistent slots.
The compiler allows at most 96 primitives and two blocks per complete program.

## Baselines and decision rule

The primary external baselines are the official three-run mean IVG no-prescreen
and prescreen top-ten AUC values. COMPOSE beats a comparator only when the
measured AUC is strictly greater. The preceding single-anchor generic-neighborhood
wave is the internal baseline. Negative margins, route failures and abstentions
are first-class outcomes.

If the panel-informed programs improve top-ten performance, that supports richer
task-appropriate program coverage in this disclosed development regime. It does
not establish that COMPOSE would discover the panel structures without that
supervision. If they fail, the result rejects this specific structural panel as
sufficient under the frozen protocol.

## Acceptance

- The contract, source root, oracle assets and external identities validate.
- Exactly 30 canonical-unique supported endpoints replay from the unrelated root.
- The curriculum is sealed from clean committed code before scoring.
- Exactly 33 query receipts complete without retries or replacements.
- Machine-readable results include exact molecules, scores, timing, metrics,
  margins, implementation hashes, code revision and scientific limitations.

## Measured result, 2026-09-13

All 33 locked queries completed without retry or replacement. Every task
improved over its single-anchor generic-neighborhood baseline and exceeded both
official IVG comparator means.

GSK3B's best score was 1.00 and final top-ten mean was 0.999. JNK3's best
score was 0.98 and final top-ten mean was 0.972. QED's best score was
0.948442042792 and final top-ten mean was 0.948442042348. The result supports
the narrow conclusion that task-appropriate, panel-informed program targets
preserve high-scoring neighborhoods better than a single anchor plus generic
one-edit variants under this answer-known development protocol.

The result does not show autonomous discovery or performance without public
candidate-structure supervision. The 30 endpoints were predeclared from exact
panel transcriptions or explicitly labeled panel-derived variants, then compiled
and replayed through COMPOSE before scoring. The authoritative payload SHA-256
is `b8248f547a24ca691f9a729cfe3fe3629ba0c2e2cee8e47ef7fdbaad7c17d022`.
