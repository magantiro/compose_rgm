# Complete-edit chooser: paid-data development

## Identity and scope

COMPOSE remains an executable stochastic process over supported complete molecular
graphs. This task changes a controller proposal channel, not the executor or frozen
reference. The output is a score and sampling distribution over a supplied set of
complete pendant-exchange plans. Plans compile to the same primitive executor;
they are not committed endpoints or a fixed fragment vocabulary. The existing
generic and other macro channels remain available and unchanged.

The immediate hypothesis is that using both beneficial and damaging paid edits,
conditioned on retained source context, removed material, added material and
attachment, ranks complete transformations better than uniform cuts or positive-only
replay. This is an endpoint-outcome predictor, not future value or exact Doob control.

Authorized here: local CPU preparation and fitting using existing paid Perindopril
MPO development data. Zero new oracle calls, no Modal job, no accelerator, no
reference-model training. One prepare step and one fixed-recipe evaluation, each
bounded to 300 seconds. Historical prescreening and development labels remain
charged to the warm-start regime. No benchmark-success claim follows from this test.

## Frozen recipe, before fitting

- Training/calibration pool: the 173 compiled edit receipts already preserved by
  contextual replay, plus its subsequent 128 proposal attempts and the initial
  donor probe's recorded noncompiled attempts (completion targets only). Retain negative
  outcomes. Deduplicate exact source/product edges, preserving all origins.
- Calibration: canonical parent groups assigned by SHA-256 of seed 20261010 and
  parent identity, one fifth held out. Remove training edges whose product equals
  a calibration source or scored product. This is development, not sealed testing.
- Chronological audit: donor outcomes in the two completed local-guidance runs.
  Exclude source/product overlap with any fit-time scored molecule. Related
  scaffolds are allowed and reported; no scaffold-generalization claim.
- Split before deriving reusable feature matrices or fitting parameters. No
  vocabulary, scaler, kernel width or hyperparameter is selected using audit data.
- Fixed kernel ridge, ridge 1.0; source-balanced weights. Input is three graph
  bags (source attachment context, removed component, added component), their
  joint similarity, and fixed-scale size/cycle/atom statistics. Bag similarity is
  count-dot Tanimoto after fixed hashing to 8192 columns; numeric counts are divided
  by 8 and use a unit-width Gaussian kernel. Reuse the exact
  graph/cut representation. Kernel components have equal weights. Predict the
  complete-edit score difference from the paid source score.
- Separate completion regression learns observed compiler success/failure, never
  fabricates an oracle label for a failed attempt. No calibrated uncertainty or
  completion probability is claimed. Completion estimates are diagnostic only.
- Comparators: uniform selection; positive-only contextual replay scores; a
  same-data endpoint-only kernel predictor. All evaluated on the identical paid,
  canonical-deduplicated candidate pools. This is ranking among logged candidates,
  not unbiased off-policy estimation or fresh generation.
- Proposed sampling: 20% original positive base distribution plus 80% bounded
  score tilt (temperature 0.05). This defines a proposal-mark policy, not an
  invariant canonical molecular law or a change to kappa. Compare greedy ranking
  and this fixed mixture; preserve all supplied base support.

## Observable and decision

Report mean selected gain, improvement precision/coverage, source counts,
available positive edges, MAE, canonical diversity, completion error, and feature,
fit and scoring time. Compare per-parent selections only when at least two distinct
scored choices exist. Report all other rows and exclusions separately.

Advance only if both calibration and chronological ranking improve the mean gain
over uniform without losing improvement coverage to the endpoint-only comparator.
With fewer than five eligible chronological parent pools or no positive outcomes,
the result is explicitly inconclusive for improvement discovery. A positive result
supports a bounded fresh proposal experiment, not an automatic benchmark launch.
A negative result stops this fixed recipe. An inconclusive result identifies the
specific missing contrast rather than repeating long optimization runs.

## Limits

This channel covers single-bridge component exchange within the current 48-slot,
at-most-40-heavy-atom compiler support. It does not learn every COMPOSE operator.
Other channels retain broader supported chemistry. Exact states come from receipts,
never reconstructed from SMILES for replay. Molecular fingerprints/scaffolds used
solely for assessment do not define executor semantics. Historical raw data lack
some modern end-to-end provenance; inherited limitations remain explicit.
