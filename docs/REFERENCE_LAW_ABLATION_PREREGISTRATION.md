# Reference-law ablation — preregistration

**Status: PREREGISTERED BEFORE ANY PARETO CONTROLLER OUTCOME EXISTS.**
Written while the held-out retargeting prefixes compile and before Lane 4's
Stage 0 tradeoff census has reported. Nothing here may be revised after a
controller result is visible.

## The question a reviewer will ask, and why it is now live

> If an unlearned same-support law moves farther, and control supplies the goal
> direction anyway, why is the learned `R_theta` needed at all?

Before Lane 1 this was hypothetical. It is now live, because Lane 1's 36-source
result landed on **`incomparable`** rather than dominance: iterated `R_theta`
has materially better chemical-envelope fidelity (+0.046 [+0.005, +0.097]) and
materially lower mobility (−0.246 [−0.309, −0.182]) than the empirical-family
baseline over identical support.

Claim 1 shows `R_theta` predicts held-out successors far better than
support-matched alternatives. Lane 1 characterises what that buys and costs when
iterated **uncontrolled**. Neither answers whether the learned reference still
matters **once the control machinery is attached** — which is the configuration
the paper actually deploys. This ablation closes that loop.

## The comparison

```
        same controller  +  R_theta
   vs   same controller  +  Q_empirical_family
```

Identical in every other respect: legal support, source panel, goals and
preference vectors, horizon, controller algorithm, oracle budget, candidate
limits, seeds. **Only the reference probabilities change.**

**The continuation values must be computed under the corresponding reference
law.** If verified control is used, the empirical-family arm's rollouts must be
generated by the empirical-family law. Using `R_theta`-derived values to control
the empirical-family reference would measure a hybrid that neither arm
represents, and would silently smuggle the learned law back into its own
control.

## Where it runs — declared before Stage 0 reports

**Primary host: Pareto development, if Lane 4's Stage 0 geometry gate passes.**
Preferred because a target-free preference goal has no privileged answer
structure and no Tanimoto-to-the-answer heuristic, so it exposes the
plausibility/purpose decomposition cleanly.

**Fallback, if Stage 0 fails outright:** the first task in Lane 3's frozen
conventional-optimization order that passes its own headroom and applicability
gate. First in the frozen order — not the task where `R_theta` looks best.

## What is measured

Objective performance alone is **insufficient and would be misleading**, because
Lane 1 established that the two references trade mobility against fidelity. A
faster-drifting reference can look like it wins on the objective purely by
moving more aggressively, while leaving the chemical envelope the learned law
respects. Both families are therefore primary:

| family | measures |
|---|---|
| goal attainment | Pareto hypervolume or task objective; feasibility rate |
| chemical fidelity | held-in descriptor-envelope retention, using Lane 1's frozen definition and its measured 0.9639 self-retention ceiling |
| structure | source preservation, endpoint structural diversity |
| cost | both oracle counters — `unique_valid_canonical_evaluations` and `oracle_requests`, never one alone |

Source-level paired bootstrap; the source is the independent unit.

## All four outcomes are declared informative in advance

| outcome | reading |
|---|---|
| comparable objective, **better fidelity** for `R_theta` | strong validation — the learned reference buys chemistry, not raw optimization |
| **better on both** | strongest available outcome |
| **same on everything** | the learned reference may not be necessary under control. The reviewer's concern is legitimate and must be reported as such |
| **empirical-family better** | a genuine challenge to the architecture. Report it. Do not bury it, and do not go looking for a task where the result reverses |

No dominance is assumed. Declaring the unfavourable readings here, in advance,
is what makes the favourable ones worth anything.

## Barred

- Choosing the host task after seeing where `R_theta` performs better.
- Reporting objective quality without fidelity, or fidelity without objective
  quality.
- Substituting one oracle counter for the other.
- Running it on exact-target recovery. That panel is sealed and closed, and its
  Tanimoto-to-the-answer heuristic would confound the comparison.
- Any statistic whose sign is fixed by construction — the project-wide rule, and
  five instances have already been caught here.

## The fidelity ceiling is 0.9639, not 1.0

The descriptor envelope was calibrated on the **held-in molecular population**
(`training_source_keys`, 96,094 molecules, 0.5%–99.5% quantiles, envelope
`fb369161`). It was **not** calibrated against `R_theta` or any arm.

The point is simpler and applies symmetrically:

> Even molecules drawn from the population that *defines* the envelope achieve
> only **0.9639** retention. 1.0 is not the attainable reference baseline for
> any arm.

So an arm at 0.95 is close to the empirical reference ceiling, not "5% drift
from perfect". Report the **raw retention fraction** always; a normalized
`F_arm / 0.9639` may accompany it where useful, but normalization must never
replace the absolute number. The same envelope and the same ceiling apply to
both reference-law arms.

## The verdict is two-dimensional, and its categories are fixed here

Objective attainment and chemical fidelity are both primary and must **not** be
collapsed into a weighted scalar invented after the results are visible.
Mirroring Lane 1's frontier, the four verdicts are declared now:

| verdict | condition |
|---|---|
| **dominates** | better on one primary axis, no worse on the other |
| **dominated** | the converse |
| **incomparable** | one arm trades objective attainment for fidelity — both differences resolved, in opposite directions |
| **unresolved** | intervals do not support a meaningful difference on either axis |

`incomparable` is a real, publishable outcome and must not be presented as a win
for either law. Lane 1 already returned it once; there is no reason to assume
this ablation cannot.
