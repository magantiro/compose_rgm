# Parameterized ring options, bounded development scope

User authorization, 2026-09-08: expose existing ring-size, composition and
refinement contracts in the local/global controller, with minimal focused
verification. COMPOSE remains the learned executable rewrite process, not a
ring catalog. Outputs are sampled primitive trajectories with complete valid
states; this integration asks whether the optional construction channels
reliably implement their declared structural requests.

## Scope and semantics

New explicit options encode pendant/fused attachment, size five/six, exact
C/N/O counts, aromatic/nonaromatic/saturated state, and zero to two subsequent
ring-scoped refinement steps. The default opt-in menu has 20 data-independent
requests: carbon-only or one N/O, with electronically compatible aromatic
variants. The API supports other declared C/N/O quotas. No winner structures,
frequencies, fragments, rewards, or templates are inputs. This menu is narrower
than the generator, whose generic and historical options remain unchanged.

A pendant program grows exactly the requested ring-size atoms and closes only
between its recorded first and last new atoms. A fused program grows size-2
atoms across a recorded existing ring edge. Both end in one real closure.
Attachment sites, cycle bond-order assignments, and placements satisfying the
residual composition quota are proposal variables. Electronic assignments are
enumerated from bond/valence conditions, not from a finite molecule library.
Impossible requests have empty support, with no fallback to decoration.

The initial reference is uniform over product-applicable attachment/bond-order
branches, then uses the existing macro action distribution within a branch.
After the first edit, the branch and exact persistent-slot path are fixed.
The residual quota excludes choices that cannot complete the requested counts.
Descriptor/region conditioning precedes the inherited cap for this NEW channel,
as in the opt-in expansion channel; old option laws/cap order are unchanged.
This is a declared augmented mark-law proposal, not a claim of molecular
representation invariance or a whole-path KL bound.

Q(M) still allocates the same region bundles. Parameterized options join the
existing purpose-balanced, untrained Q(o), with its unchanged exploration
mixture and generic permanently active. More parameter names do not multiply
region draws. The inner KL tilt, kappa=1, R_theta, structural committor,
executor, charge policy, medicinal gate, and 40-active-atom limit are unchanged.
Physical products are cached by exact graph and action identity for the new
channels; augmented branch/option states retain their separate probabilities.

Completion checks the recorded cycle, original induced connectivity, atom
identity/charge retention, exactly one cycle-rank gain, attachment topology,
composition quota and electronic state. Optional refinement starts only after
that witness and uses ring-scoped existing restatement descriptors. It may
change the new ring's composition/electronics, which are reported as refinement,
not silently treated as matching the original construction target. Incomplete
programs remain search states, not completed oracle candidates.

T4 enables this through explicit `ring_program_options` or
`include_ring_programs=true`. Neither flag is enabled by default. Option,
parameter, progress and exact-state identities are retained in saved traces.

## Minimal check and audit

Reuse existing option/fused/expansion regression tests. Add only requested-ring
behavior, scope/quota identity, and initial applicability/prior checks. No full
repository suite is an iteration prerequisite and no training is authorized.

The bounded local capability audit uses synthetic benzene, uniform neutral
primitive candidates from the existing broad-organic enumerator, the production
executor and unchanged medicinal gate. It is NOT R_theta or docking evidence.
Run each of the 20 default requests once with seed 0, plus one declared pendant
six-member C5N1 nonaromatic request with one refinement step. No retries or
seed/weight selection. Per request: at most 256 public executor calls and a
30-second deadline. One CPU worker, no GPU, zero docking; expected scale is
four to eight sampled edits per request. Save exact traces, hashes, all failed
requests, realized ring descriptors, executor work and time. Require independent
endpoint counts/topology and all-step validity in addition to the kernel witness.

This audit cannot rank search algorithms or establish production completion
probability. Existing same-generator reference and controlled modes remain
available for a later matched comparison. A subsequent T4 run requires a new
bounded run identity; old feedback contracts/results must not be overwritten
or silently resumed with changed options.
