# Opt-in stateful fused-ring option

Prospective decision, 2026-09-07. Authority: the user approved proceeding with
the stateful fused program after the bounded construction witnesses. This is
an integration and engineering-validation milestone, not T4 promotion or
training authority.

## Identity, support, and frozen boundaries

COMPOSE learns an executable marked molecular rewrite process. The question
here is whether a five-step, stateful proposal channel can construct an added
six-carbon aromatic cycle sharing an existing ring edge, while retaining the
region controller and the unchanged executor. Outputs are executable primitive
paths and complete valid molecular states, not transplanted ring endpoints.

This optional channel has deliberately narrower support than COMPOSE: four
single-neighbor carbon insertions, with attachment bond orders 1, 2, 1, 2,
then closure to the other end of a selected existing carbon ring edge. Both
edge endpoints must lie in the selected mutable region, have available H,
and belong to a cycle. Maximum active size remains 40. Persistent slots,
charge policy, vocabulary, and executor semantics remain unchanged. No ring
catalog, multi-neighbor insertion, stereochemistry, or charge-changing move
is added. Other sizes, heterocycles, pendant rings, and general rebuilding
remain the responsibility of existing channels, not claimed support here.

Keep the default option registry and T4 path unchanged. The new option is
explicitly enabled, then subject to the same purpose-balanced untrained prior
and exploration floor. Keep generic permanently available. Keep Q(M), R_theta,
kappa = 1, and inherited macro temperature/exploration unchanged. The existing
eleven-step BUILD_RING_SYSTEM remains unchanged. Inspected winners are not
inputs, fragments, rewards, similarity targets, or option-weight supervision.

## Augmented reference law

A bundle remains one (parent, region, option) draw. Program state contains the
oriented fusion edge and ordered newly created persistent slots, in addition
to the existing graph, region context, lineage, phase, and remaining horizon.

At the first physical edit, enumerate eligible oriented edges. For each edge,
intersect descriptor-matching actions with region admissibility, the inherited
proposal support (global 300 union per-family 20), and valid executor products.
Let E+ contain edges with a nonempty resulting first-step row. Define

    R(e, a | s) = 1 / |E+| * R_macro(a | s, e).

R_macro is the existing macro_action_distribution on that intersection.
Subsequent rows keep the selected edge and extend only the recorded path tip,
then close only to the other endpoint. No best-edge choice, greedy endpoint
constructor, hidden retries, or added outer-region draws are allowed. Distinct
edge states may share a physical first action; execute that action once and
retain the separate augmented successor probabilities. This is control of a
declared augmented mark law, not a representation-invariant molecular kernel.
The KL bound is per decision relative to this reference, not a whole-path bound.

Conditioning never bypasses the inherited proposal cap. Record descriptor
matches before and after that cap and after product validation. A missing
row is a support/validation failure at this stage, not proof of molecular
unreachability. Executor-budget exhaustion publishes no partial row.

Every transition uses the same executor and product/context checks. At closure,
independently require four new atoms, the exact six-cycle through the recorded
shared edge, no extra new-to-old attachments, preserved original atom identities
and induced connectivity, graph cycle-rank gain one, and aromaticity of the
new cycle. A ring-count increase alone does not certify a fused construction.

## Validation and next launch boundary

First validate model-free fixtures using actual executor actions: normalized
edge/mark probabilities, action sharing without state aliasing, default-path
parity, continuation credit across different edges, per-step KL, phase/lineage
keys, sparse slots, false fused witnesses, support-cap exclusion, invalid
products, empty applicability, budget interruption, and serialization.

Add an explicit reference-only sampler with zero lookahead and no terminal
scoring. Compare guidance to that same-generator reference at matched executor
budgets, not to a deterministic constructor. The synthetic benzene engineering
fixture is not a molecular performance panel; completeness there cannot rank
ring methods or establish chemistry coverage. Save exact states and provenance
for any numeric run and report negative outcomes without changing the contract.

The first recorded local integration audit is one reference-only trajectory,
seed 0, on synthetic benzene with 48 persistent slots, using the unchanged
neutral primitive enumerator and uniform raw weights (no correlated RingCore
tracelets). Keep the inherited support cap. Limit total public executor calls
to 256 and check a 30-second safety deadline between calls. One CPU process,
one thread, no GPU, zero docking. Expected work is five sampled transitions
plus product validation; measure the actual work. Record all attempted work,
including a cap-induced or chemistry failure. Do not retry a failed seed.

Next prepare ONE capped production-reference audit using the frozen checkpoint,
not an exhaustive suffix tree. Inventory compatible artifacts before launching;
freeze the source/region, seed, total public-executor cap, stop time, resource
census, input hashes, and immutable output identity in its run contract first.
Only after that cost/support result is reviewed should a matched guided audit
or T4 docking be authorized. No remote run is authorized solely by this file.
