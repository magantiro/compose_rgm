## Fixed recipe, recorded before validation

Reuse the existing radius-2, 2048-bit Morgan bootstrap-ridge recipe: eight
bootstrap fits, ridge=1, warmup=16. Use the ensemble mean, not a Thompson draw
or an alleged uncertainty bound. Solve the identical ridge problem in its
sample-space dual to avoid eight 2048-by-2048 solves for tens of observations.
Verify against the primal on a small deterministic fixture. Snapshot the
complete counted archive prefix before a round, including failed-oracle
exclusions, seed, training identities and fitted coefficients. Never fit on
current-round candidates or labels. Do not change the existing post-hoc scorer.

For endpoint y, use the unchanged T4 feasibility predicate F(y) and

    G(y) = F(y) exp(-max(0, predicted_docking(y) - min(training_scores)) / s)
    s = max(1, standard_deviation(training_scores)).

This is a bounded monotone heuristic desirability, NOT a calibrated success
probability. Predictions beyond the observed best saturate, rather than buying
arbitrarily stronger guidance. Ring count, IVG similarity and novelty bonuses
are absent. Compute F only at the original option horizon, never on enabling
intermediates. Reuse the exact finite-horizon reference backup and frozen KL
tilt. All branches must complete before values may change a decision.

For the first integration, each parent has a separate lifetime lookahead share
of 512 public executor calls, 128 row expansions and 256 terminal evaluations.
This work also counts against the existing parent and round ceilings. Cache
exact augmented rows and values. Budget exhaustion or zero terminal mass uses
the existing structural decision, with an explicit reason; no partial-tree
ranking, suffix-depth truncation or recycled extra outer draws. This bounded
exact implementation can abstain on wide generic support. It is not claimed
to solve full molecular-scale planning efficiently.
