# Bounded pendant/fused construction probe

Date: 2026-09-07. Authority: the user's request to focus on controlled ring
construction before resuming objective-directed search.

## Identity and boundary

COMPOSE remains an executable molecular rewrite process. This probe asks only
whether two existing descriptor constructors produce the requested topology
and electronic state through the unchanged executor. Its output is a complete
slot-addressed execution witness or an explicit failure. It is not a learned
controller comparison, discovery benchmark, or training/launch authorization.

Reuse `build_ring_system_exact` and `build_fused_ring_exact` from the existing
macro engine. These descriptor constructors are NOT the registered eleven-step
`BUILD_RING_SYSTEM` option and are not silently substituted into that option.
They use deterministic descriptor selection, not the frozen KL controller.
Passing this probe therefore cannot qualify the integrated three-level policy.

The reference is the existing neutral primitive candidate enumerator with the
declared broad-organic vocabulary and uniform weights, not R_theta. It omits
correlated RingCore tracelets and is an explicitly restricted engineering lane.
Every attempted edit uses the production editing executor. No new operator,
ring template library, checkpoint, objective, region prior, option prior, macro
contract, support cap, or kappa is introduced or changed.

## Frozen fixture and acceptance

Before running: use one synthetic benzene source (`c1ccccc1`), parsed once and
padded to 48 persistent slots, with the production limit of 40 active atoms.
Run exactly two requests: a six-carbon aromatic pendant ring and a six-carbon
aromatic fused ring. Use the existing first-site tie-breaking, no refinement,
and the existing maximum of 24 aromatization candidates. Uniform candidate
weights make this deterministic; no RNG, docking label, or winner is an input.
This fixture is not a training, calibration, or final-test molecule panel.

Cap each request at 256 public executor applications, including nested calls,
and a 30-second safety deadline checked between enumeration/execution calls.
A timeout or exhausted budget is incomplete work, not chemical unreachability.
No retry with different chemistry, site, quota, or relaxed acceptance is allowed.
The two requests are independent CPU tasks run serially, with one thread and
no GPU/cloud allocation. The expected scale is a few primitive steps; actual
time and enumeration work must be measured rather than inferred from docking.

Accept only if every committed state is connected, valid, charge-preserving,
and within the active-atom limit, and the exact initial atom identities and
initial induced connectivity are retained. Match the final molecule back to
an actually executed state, never regenerate a state from its endpoint SMILES.
Require cycle-rank gain one and aromatic-ring gain one. Require ring-system
gain one for pendant and zero for fused construction. Independently inspect
the exact newly added slots: they must form the requested six-cycle, either
alone with one attachment to the old graph (pendant), or with exactly the two
adjacent old ring atoms forming the shared edge (fused). Ring-count changes or
a constructor's own `OK` flag alone cannot pass this check.

Record all executor receipts, successful committed path states, exact cache
identity, enumerated candidate counts, timing, budget stops, and source/code/
configuration hashes. Test wrong-topology rejection, interrupted work, exact
slot-key caching, determinism, and saved-path continuity. Preserve all outcomes.
