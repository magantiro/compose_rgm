# Autonomous complete-option delayed-credit audit

This zero-oracle retrospective audit asks whether prior autonomous COMPOSE
genealogies contain enough multi-option recovery signal to justify a new
budget-conditioned controller. It does not evaluate benchmark performance.

The generated object is a complete executable option transition between exact
persistent-slot molecular states. The target at horizon `b` is the best score
actually witnessed in that proposal's own descendants over the next `b` option
boundaries, with retention of the scored parent as the stop action. This is an
achieved behavior-policy return. It is not an endpoint property label, an
expectation under the frozen reference process, a calibrated committor, or an
exact Doob backward value.

Ten complete Perindopril MPO development results supply the histories. Their
content hashes and durable Modal-volume identities are frozen in
`configs/pmo_delayed_credit_audit.json`. The public winner is not read. The
histories remain exposed development data, and some ancestors and a prior value
head had winner exposure. No result from this audit is a sealed or matched PMO
claim.

For each scored complete option, the audit records parent and product identity,
root lineage, option, region scale, arm, boundary, and full witnessed chain.
Future labels never cross an arm or run. Root groups sharing any parent or
product identity are merged before validation. A fixed context kernel combines
the parent molecular kernel with exact-option, option-family, interface, and
release-scale kernels. Leave-one-connected-root-group-out kernel ridge compares:

- an endpoint model trained only on the one-option return;
- a future model trained on the witnessed `b`-option return;
- retention of the parent score.

The audit evaluates three fixed representations: parent plus option context,
the complete product state, and the realized parent-to-product edit. The
realized-edit kernel is primary because it is the implementable option-boundary
controller: COMPOSE can generate a complete valid option endpoint, inspect the
actual molecular change, and twist particle survival before purchasing that
endpoint's oracle label. The parent-only option model is the cheaper diagnostic;
the product-only state value tests whether the Markov endpoint alone suffices.

Both learned models regress improvement over the known parent score, not the
absolute task score. The parent is an already paid optimizer state and its score
is part of the controller state. At prediction time, negative gains are clipped
to the available stop action and gains above one are clipped to the PMO range.

The useful positive is not merely a lower training error. At the longest fixed
horizon, delayed recoveries must be numerous enough to learn from, and the
future-labelled model must improve out-of-root error and within-parent choice
regret over the identical endpoint-labelled model. A negative result rejects
this data/model pairing before a new oracle call. Both paired effects use a
4,096-draw leakage-connected-root bootstrap and must have a positive 95 percent
lower bound for the audit to call the signal robust. A positive result supports
freezing a controller-side potential for a bounded causal probe; it does not
authorize that probe or establish optimization improvement.

Run locally against downloaded content-addressed artifacts:

```bash
PYTHONPATH=src python3 tools/pmo_delayed_credit_audit.py \
  --artifact-root /private/tmp
```

The current audit did not meet the robust future-value gate. The next bounded
mechanism therefore uses the complete option or plan itself as the temporal
abstraction. `tools/pmo_complete_plan_ranker.py` fits a product-state signed
endpoint-delta model only on autonomous scored complete options, then freezes predictions
for every candidate in the already locked 95-candidate plan-pool assay. This
does not relabel the endpoint model as future value. Instead, the plan absorbs
delayed credit across its internal primitive edits, and the ranker evaluates the
complete valid molecule produced by that plan. Scoring all three locked roles is
still required to test whether this ranker or the plan pools are useful.

The signed delta is distinct from archive value. The archive supplies the exact
parent as a stop action; the screener must retain negative labels so it can reject
destructive completed plans instead of mapping every loss to the same zero gain.

The signed-delta repair passed the already-paid temporal holdout. Score RMSE is
0.119 versus 0.252 for the parent-retention baseline, score Spearman is 0.722,
and gain Spearman is 0.402. Across nine exact-parent choice sets, the ranker's
selected endpoints average 0.639, compared with 0.548 for uniform selection and
0.657 for the within-pool oracle. This is evidence that complete-plan endpoints
can be screened before paying for them; it is not yet evidence that the locked
95-candidate pool contains a new champion.
