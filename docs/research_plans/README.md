# Research plans

These three standalone HTML documents are the canonical project strategy
artifacts. They intentionally include their own styling so a collaborator can
open them directly without a build step.

- `paper1_compose_methods.html`: the COMPOSE RGM methods-paper plan.
- `paper2_compose_lipid.html`: the COMPOSE-Lipid translational paper plan.
- `compose_two_paper_execution_plan.html`: the detailed shared execution plan.

The methods plan treats stochastic rewriting plus Generator Matching as the
core intellectual contribution, with validity-closed conditional generation as
the headline empirical opportunity. The lipid plan imports that model in a
biologically legible way and reserves detailed ML theory for Paper 1.
