# Frozen-model inference acceleration

User authorization, 2026-09-10: remove the measured enumeration/startup bottleneck
before the next controller experiment. This task consumes zero new property or
docking calls and does not train or select a reference model.

Problem/output: load the existing selected frozen model without reconstructing
its training corpus on every cold worker, and compute the same executable marked
law with the existing exact-state serialization cache. COMPOSE's declared
vocabulary, charge-preserving support, size, canonicalization and executor remain
unchanged. The claim is computational equivalence and measured speed, not better
search quality or universal expressibility.

1. Under the original qualified process identity, load and authenticate the
   existing model once. Export a CPU inference package with physical file hash,
   selected tensor-state hash, input checkpoint/run-path hashes, source inventory,
   software and producer revision. Validate a reload against the original model
   on one complete production law. Reuse a complete matching export.
2. Use exact archived states from the measured slow worker: its parent and the
   two completed six-membered pendant-ring products. No SMILES reconstruction,
   new molecular search, winner input, oracle label, or endpoint selection occurs.
3. In a separately source-bound acceleration probe, load that same package and
   compare the committed baseline serializer with the existing cache implementation
   on all three states, three alternating repetitions each. Compare every ordered
   encoded mark and probability exactly; on the first repetition, compare every
   executed exact product, canonical identity and validity outcome. Record timing
   outside execution replay. The baseline-function substitution is confined to
   this diagnostic process and always restored; it is never a deployment mechanism.
4. The only allowed runtime implementation changes are the two known serialization
   cache files from `ff31dbd`. All model and other executable dependencies must
   match the export. Historical corpus/process manifests are not rehashed or
   relabeled. The candidate runtime has its own identity. Until the actual frozen-
   model parity probe passes, the acceleration is not admitted for search.

Acceptance: authenticated export/reload, unchanged selected tensors and production
law, exact paired mark/probability/product parity, faster median enumeration on
each of the three states, and measured package-load time versus the old runtime.
An error or mismatch is a failed result, not grounds to loosen tolerances. Small
source-bound fixtures cover corrupted packages, unauthorized source drift and
reload behavior; reuse the existing focused cache tests. No broad suite is an
iteration gate; full-suite verification remains a release/milestone requirement.

Compute: one reusable export worker and one acceleration-probe worker, sequential
stages, each one CPU/8 GiB, no GPU, at most 20 minutes per stage, no automatic
retries. Expected total wall time 5-12 minutes plus image build, conservative cap
40 CPU-minutes and $2 reserved cost. Publish stage/row heartbeats and completed
receipts. Check for and reuse complete compatible exports/rows before computing.
The paired probe is the useful production benchmark, not a disposable canary.
Long-run search quality and further oracle budgets remain separate decisions.
