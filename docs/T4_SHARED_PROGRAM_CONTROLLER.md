## Fixed next recipe

attachments, uninterrupted completion, variable parameters, branch recombination,
and exact serial execution. Retain 70/20/10 mutation/recombination/broad proposal
allocation, 32 primitives, eight blocks, bounded binding enumeration and the same
rank-based adaptation rule. Do not add a future-value head, additional particles
or task-specific structural exceptions in this comparison.

The shared library contains 146 unique typed programs from the existing PARP1
constructions and 77 additional verified public-winner route records, including
shrinkage and remodeling. Dependency-closed branches are deduplicated by typed
program identity. Bind the common library to each seed's attachment environments.
Transfer program logic, not exact slot indices or docking labels. Genuinely scored programs can
enter the shared library with their originating task and source identity retained.
Freeze the initial library for a paired comparison; expansion during a lifelong
transfer experiment requires an explicit common task order and information ledger.

delta=0.4. These choices
precede new controller outcomes. Use their saved exact initial states, not

Treat these four cells as a development curriculum. Freeze the architecture and

## Cold-start boundary

A new target has no measured program archive. First bind and execute shared
programs, lock distinct eligible endpoints, and obtain task-specific scores.
Only then admit those complete records to `ProgramOptimizer`. Structural
programs without new-target scores are not assigned invented labels, and known
PARP1 scores are never reused as JAK2/FA7 observations. The static and adaptive
program arms receive the same initialization information and differ only after
new task scores arrive. An unavailable broad runtime is an explicit local-mode
failure, not a replacement chemistry channel.
