# Population-derived executable proposal channel

2026-09-11, new development authorization: the user explicitly permits changing
macros and controller parameterization, using public winners and existing labels.
This does not modify any previously frozen experiment or its scientific claims.

Problem: repeated small learned/reference option populations have not improved
the warm perindopril best, 0.5222329678670935. An existing, separate prescreen bank
already contains better molecular cores. Test a coordinated graph proposal before
fitting another small endpoint or future-value head.

Output: a source-conditioned program replacing one pendant component with a
component of another complete scored molecule. Both components are selected from
oriented single-bond bridges. The atom correspondence is known from construction;
no MCS search is needed. The existing bounded compiler lowers the desired graph
to the same primitive executor and independently replays every committed state.
Retained atom identity, charge, and internal bonds must remain unchanged.

Scientific contract change: this new optional controller channel has
executor-supported paths but no claimed absolute continuity with the *learned*
reference law, kappa=1 bound, or exact Doob terminal distribution. The frozen
reference weights, executor, charge/size/coordinate semantics are unchanged.
If retained, it must coexist with generic reference/atom/bond editing; it cannot
replace COMPOSE with a finite ring-only vocabulary. Donor fragments are transient
population-dependent proposals, not the declared molecular support. This initial
isolated channel probe is not the full combined controller or an SMC comparison.

Use the previously scored perindopril top-100 ZINC bank, downloaded from
`compose-v4-artifacts/pmo_matched_init/bank_perindopril_mpo.json`. It reports
249455 historical calls, top1 0.5595028849441883 and top10 0.5366184196978077.
Verify labels after the explicit achiral projection before reuse; mismatches
abort rather than silently substituting a score. Unsupported inputs are logged.
The historical bank lacks a complete modern provenance chain; report that limit.
No IVG molecule is a donor in this first probe. Later winner-trained proposals
must be labeled separately. All this task development is already exposed.

Smallest experiment: one fixed proposal batch, seed 20260925, at most 128
uniform ordered parent/donor pairs drawn from the supported top-100 bank, uniform
bridge orientation in each. Compiler cap: 64 steps, 128 expanded states, four
children per expansion, with the unchanged deterministic compiler heuristic.
Score only replay-verified new endpoints, up to 128 new oracle calls. No outcome
changes the batch's draws. All duplicate/self/size/compiler failures remain in
the ledger. Do not use hypothetical uncompiled endpoint scores as results.
Initialization parity uses at most 100 additional physical repeat evaluations,
reported separately from new endpoint queries and the historical prescreen.
Stop local work after 300 seconds between complete restart units, retaining an
operationally truncated result. One CPU, float64 chemistry arrays, no GPU or
Modal allocation in this first probe. Benchmark the first real reusable proposal
and record proposal/replay/oracle time, not merely query count.

Decision: a new replay-verified score above the supported initialization best
earns integration with generic editing and a matched same-start comparison.
Failure to beat that best stops this unchanged proposal recipe. Low compile
coverage routes the next action to compilation only if proposals complete fast
enough; truncation is inconclusive, not evidence of absent chemistry. Supporting
channel success is not official PMO AUC or achievement of the overarching goal.

Focused tests cover a real pendant aromatic-ring transplant, exact replay,
retained-context preservation, size failure and malformed cuts. Record input and
producer hashes, full configuration, source revision/dirty snapshot, library
versions, initialization exclusions, original labels, every attempt and oracle
call in a durable task-specific directory. No full-suite or milestone claim.
