# Fresh-seed linker path-binding signal

This is a **zero-oracle development gate**, not an official fragment benchmark
row. The v2 self-hashed contract froze untouched seed 4, ten released linker
prompts, twenty attempts per prompt and the thresholds before the run. The
exact old/new sampler, runner, checkpoint, prompt and official InVirtuoGen
evaluator SHA-256 identities were verified by
`scripts/analyze_fragment_linker_path_binding_validation.py`.

| Quantity | Old site-matching | Constraint-bound learned payload |
|---|---:|---:|
| Attempts | 200 | 200 |
| Committed endpoints | 24 | 149 |
| Exact chemical validity of commits | 24/24 | 149/149 |
| RDKit required-fragment containment | 24/24 | 149/149 |
| Genuine paths longer than the one-atom seed | 24/200 | 147/200 |
| Official quality, unweighted prompt mean | 0.065 | 0.180 |
| Official uniqueness, unweighted prompt mean | 0.630 | 0.686 |
| Official diversity, unweighted prompt mean | 0.193 | 0.496 |

The genuine-linker gain is +0.615 per attempt; all five frozen **numeric**
gates pass. The treatment has two committed/emitted endpoints still at the
seeded path length. Those are valid and fragment-containing but are **not**
counted as full linker successes. `report.json` initially mislabeled all 149
emissions as full task successes; `report_corrected.json` preserves the
correction without overwriting the first artifact. The correct full structural
success count is 147. Exact graph-slot lock preservation is an executor and
`RegionLock` invariant tested in the focused suite, not directly reconstructible
from canonical SMILES; this remains a separate qualification check.

`first_distinct_grid.png` shows the first two distinct committed molecules per
prompt, selected in emission order. Visual inspection supports that real
2–5-atom paths were made and that aromatic rings are generally intact in this
small grid. It also shows odd valid chemistry, including an S–H-rich linkage
in one Futibatinib sample. The official quality mean of 0.180 is still low.
The treatment's higher output rate therefore does not by itself establish
medicinal quality or parity with a model that starts from disconnected cores.

The one-atom bridge was supplied by the harness in **both** arms to keep every
COMPOSE state a connected valid molecule. It is not generated by the model.
This gate qualifies a larger frozen reproducibility test, but the constructed
bridge and the previously classified support extension on eight prompts keep
the official linker comparator row withheld until semantics are matched.
