# Complete-option delayed credit and plan ranking

This directory records a zero-new-oracle decision sequence on exposed
Perindopril MPO development data.

`audit.json` contains 1,207 scored complete-option occurrences from ten prior
autonomous COMPOSE runs. At a three-option horizon, 51 of 903 temporary-loss
branches later recovered above their paid parent. A witnessed-future target
improved realized-edit RMSE from 0.05235 to 0.05203 and gain Spearman from 0.299
to 0.345, but the root-clustered confidence intervals crossed zero. The declared
verdict is therefore directional, not robust. This target is not deployed as a
future-value or Doob potential.

`plan_ranker_lock.json` implements the fallback temporal abstraction: execute a
multi-primitive option or plan to one complete valid molecular endpoint, retain
the paid parent as a stop action, and predict the signed endpoint delta. The
ranker preserves damaging examples instead of truncating every loss to zero. It
was fit only to historical autonomous complete options and prospectively locks
predictions for all 95 already-generated, still-unscored plan-pool candidates.
Only five are predicted to improve their parent; 32 pool choices contain 25
actor-top, six uniform-hash, and one largest-release candidate. The public PMO
winner is not a training input.

`plan_ranker_holdout.json` evaluates the frozen ranker on the earlier 58-call
complete-plan policy run, which was not used for fitting. This temporal holdout
is still exposed development evidence. Across its distinct products, score RMSE
is 0.119 versus 0.252 for retaining the parent, score Spearman is 0.722, and gain
Spearman is 0.402. In nine parent-level choice sets, predicted selection averages
0.639 versus 0.548 for uniform selection and 0.657 for the within-set oracle.
The file contains the parent-bootstrap interval for the selected-minus-uniform
advantage.

The unscored 95-candidate assay remains the decisive prospective development
test. It must score every locked role, not only the ranker's choices, so proposal
fertility and ranking can be separated. It requires an explicit authorization
for exactly 95 new PMO oracle calls. No such call is made by these artifacts.
