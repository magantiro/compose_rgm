# Matched parent/edit learning cycles

User-approved development budget: 108 docking calls and 24,000 PMO queries,
$20 combined reserved cost, up to 30 simultaneous containers. The concrete launch
uses twelve shared workers, two group drivers and two confirmation workers.
All are CPU-only with explicit memory/time ceilings and zero automatic retries.

`configs/parent_edit_cycles.json` is the self-hashed launch contract. Its material
inputs include the exact warm T4 histories, common shared program library and
three task-independent PMO initialization locks. Existing PMO scores are not
included. PMO structural programs retain their declared T4-winner-derived origin.

Preparation admitted all 100 supplied initialization structures under the current
support and selected sixteen per search seed, before new PMO labels. They are
fresh imported coordinates, not reconstructed historical slot-addressed traces.
No preparation oracle calls. `prepared/initialization_audit.json` retains the
input identity, source-selection rule and exclusion list. Warm archive files
retain predecessor histories and all compatible measured observations.

The prelaunch contract copy preserves the first draft before final binding of
the update function and the pinned PyTDC oracle module hash. No molecular input
was regenerated and no result was inspected between these bindings.

Forty focused launch/dependency tests passed in 8.95 seconds; lint/format and
diff checks passed. This is not a full repository verification or benchmark
result. Launch receipts and retrieved results will be added here. Durable remote
artifacts live in `parent_edit_cycles/<run_id>/` on `compose-v4-artifacts`.

Read `docs/PARENT_EDIT_LEARNING_CYCLES.md` for the fixed hypothesis, comparisons,
query accounting and positive/negative/inconclusive decisions.
