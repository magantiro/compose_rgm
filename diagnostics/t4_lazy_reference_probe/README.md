## What changed, and what did not

The opt-in lazy-reference planner uses reference trajectory draws rather than
adaptive planning proposals. It retains full rows for committed KL decisions.
It preserves the inherited macro mixture by selecting a mixture component
before rejecting invalid products, and chooses construction branches uniformly
over product-applicable branches. Ordinary and descriptor options share the
same production product checks and exact physical-product cache. Completed
trajectories alone supply return observations; interruption is not a zero reward.

Law parity concerns completed rejection draws without an administrative stop.
Finite-compute censoring and sparse, shrunk return estimates remain limitations;
this is not an exact Doob controller or calibrated uncertainty estimator.

The menu is a collection of optional construction programs, not a vocabulary
of permitted molecules. Generic atom/bond editing stays available. Dedicated
construction currently covers pendant/fused five-/six-member C/N/O rings with
the declared electronic variants; the default menu has at most one N or O.
Broader compositions accepted by the API, generic edits, or the separate
ring-expansion implementation are not evidence that the active hierarchy can
efficiently recover every IVG winner. No menu, primitive support, executor,
R_theta, charge/size limit, 16-edit terminal objective, feasibility threshold,
exploration floor or kappa=1 changed. No IVG winner data entered guidance.
